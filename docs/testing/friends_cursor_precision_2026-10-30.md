# Точный курсор друзей — 30 октября 2026

Предыдущий этап данных для ручной проверки сохранён локальным коммитом
`4be9ffc` в dev под настроенным автором репозитория. Тесты, отчёты и
посторонние изменения в этот коммит не включены. Push не выполнялся.

## Изменения

Локальная схема Drift повышена с 28 до 29. Добавлены nullable-поля
friends_since_micros и next_friends_since_micros, а также признак
requires_cursor_repair в метаданных списка. Старые столбцы дат сохранены.

Курсор записывается и восстанавливается без потери микросекунд. Сортировка
кэша использует точную дату, затем убывающий ID, как сервер. При отсутствии
точной даты старой записи остаётся прежнее значение с секундной точностью.
Сравнение входящих друзей также учитывает микросекунды; принятие заявки,
поиск и Realtime записывают точное время через существующие пути кэша.

Миграция не удаляет друзей/заявки/медиа/чаты. Старый курсор не используется:
при следующей синхронизации берётся точная первая страница. До последней
серверной страницы восстановление не считается завершённым лишь по числу
локальных строк: старый кэш мог скрывать пропуски. Повторное обновление
головы сохраняет достигнутый точный курсор. Прогресс сохраняется после
закрытия приложения, поиск не завершает восстановление преждевременно.

Восстановление идёт обычной пагинацией, без фоновой загрузки всех страниц.
Существующие офлайн-строки сохраняются. При отсутствии пригодного курсора
loadMore использует уже объединяемую штатную синхронизацию первой страницы.
После восстановления обычная частота запросов не увеличивается, новых
каналов/таймеров нет. Серверные RPC, лимиты и миграции не менялись.

## Ручная проверка

Обновить приложение без очистки данных. Открыть друзей, пролистать до конца
и сравнить число строк со счётчиком. Проверить друга из конца через поиск,
стереть запрос и продолжить подгрузку. Повторно открыть без сети: сохранённые
друзья доступны. Для текущего локального набора использовать
`.\scripts\pagination-lab.ps1 run`.

Новых миграций Supabase применять не требуется. Пункты про аватары,
поиск друзей чужого профиля и загрузку людей рядом оставлены без изменений.
